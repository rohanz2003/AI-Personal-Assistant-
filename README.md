Enterprise AI Assistant v1.0

An AI-powered workflow automation assistant built with n8n that integrates Telegram, OpenAI, Gmail, Google Calendar, and Fireflies AI to automate communication, scheduling, and meeting management tasks.

Telegram Bot

Telegram Bot: https://t.me/Connectitbot

Features

- Telegram AI Chatbot
- OpenAI Integration
- Gmail Automation
- Google Calendar Scheduling
- Fireflies Meeting Transcript Analysis
- Conversation Memory
- Automated Task Execution
- Meeting Summaries and Action Items
- Multi-Tool AI Agent Workflow

Workflow Architecture

Telegram → AI Agent → Gmail / Calendar / Fireflies → Telegram Reply

Tech Stack

- n8n
- OpenAI API
- Telegram Bot API
- Gmail API
- Google Calendar API
- Fireflies API

Workflow Components

1. Telegram Trigger
2. AI Agent
3. OpenAI Chat Model
4. Simple Memory
5. Gmail Tool
6. Google Calendar Tool
7. Fireflies Meeting Fetch Tool
8. Fireflies Transcript Fetch Tool
9. Telegram Message Sender

Use Cases

- Personal AI Assistant

- Meeting Scheduling
- Meeting Transcript Analysis
- Task and Reminder Management
- Productivity Automation

Import Workflow

1. Download the workflow JSON file.
2. Open n8n.
3. Click "Import Workflow".
4. Select the JSON file.
5. Configure all required credentials.
6. Activate the workflow.

Required Credentials

- OpenAI API Key
- Telegram Bot Token
- Gmail OAuth Credentials
- Google Calendar OAuth Credentials
- Fireflies API Key

How to Use

1. Open the Telegram Bot:
   https://t.me/Connectitbot

2. Send a message to the bot.

3. Ask the assistant to:
   
   - Send emails
   - Schedule meetings
   - Set reminders
   - Summarize Fireflies meetings
   - Retrieve meeting action items
   - Answer questions

Example Commands

- Send an email to john@example.com about project completion.
- Schedule a meeting tomorrow at 4 PM.
- Show action items from the latest meeting.
- Summarize yesterday's client meeting.
- Set a reminder for Friday at 10 AM.
